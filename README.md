**CyberChef** — веб-приложение для выполнения операций над данными: кодирования и декодирования, преобразования форматов, вычисления хешей, сжатия и анализа данных.

## Назначение документации

Этот комплект помогает новому пользователю начать работу с CyberChef, выполнять типовые операции, составлять последовательности преобразований (рецепты) и находить решения распространённых проблем. Материалы разделены на тематические страницы и связаны внутренними ссылками.

## Основные возможности CyberChef

* кодирование и декодирование, например Base64 и Hex;
* вычисление хешей и контрольных сумм;
* преобразование текста, байтов и форматов;
* выполнение нескольких операций подряд в одном рецепте;
* загрузка файлов в поле ввода и сохранение результата;
* поиск операций и сохранение рецептов.
