# Установка и запуск CyberChef

## Вариант 1. Использование веб-версии

Самый простой способ начать работу — открыть [официальную веб-версию CyberChef](https://gchq.github.io/CyberChef/). Отдельная установка для базовых операций не требуется; нужен современный браузер с поддержкой JavaScript.

## Вариант 2. Локальный запуск через Docker

Docker позволяет запустить готовый контейнер CyberChef. Необходимо, чтобы Docker Engine или Docker Desktop был установлен и запущен.

В терминале выполните:

```bash
docker run -it -p 8080:8080 ghcr.io/gchq/cyberchef:latest
```

После запуска откройте в браузере:

```text
http://localhost:8080
```

**Ожидаемый результат:** загрузится интерфейс CyberChef, доступный на локальном компьютере. Если порт `8080` уже занят, необходимо выбрать свободный локальный порт и соответствующим образом изменить публикацию порта.

Чтобы остановить контейнер, вернитесь в терминал, в котором он запущен, и нажмите `Ctrl+C`.

## Вариант 3. Запуск из исходного кода

Для этого варианта требуются Git, Node.js версии 24 и npm. Официальный проект отмечает, что сборка ориентирована на bash-среды; Windows может потребовать дополнительной настройки.

```bash
git clone https://github.com/gchq/CyberChef.git
cd CyberChef
npm install
npm start
```

После запуска откройте:

```text
http://localhost:8080
```

- `git clone` загружает исходный код.
- `npm install` устанавливает зависимости.
- `npm start` запускает сервер разработки с автоматической перезагрузкой.

Для локальной production-сборки используется `npm run build`; результат размещается в каталоге `build/prod/`.

## Параметры и требования

| Параметр | Веб-версия | Docker | Запуск из исходного кода |
|---|---|---|---|
| Браузер | Требуется | Требуется | Требуется |
| Docker | Не требуется | Требуется | Не требуется |
| Node.js | Не требуется пользователю | Не требуется пользователю при запуске готового образа | Node.js 24 |
| Git | Не требуется | Не требуется | Требуется для клонирования |
| Адрес по умолчанию | Официальный сайт | `http://localhost:8080` | `http://localhost:8080` |

Примечание: таблица описывает обычные способы запуска, а не минимальные аппаратные требования разработчика.
