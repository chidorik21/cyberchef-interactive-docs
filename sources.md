## Использованные источники

1. **GCHQ CyberChef — официальный репозиторий и README**  
   https://github.com/gchq/CyberChef  
   Использован для описания назначения CyberChef, областей интерфейса, примеров локального запуска, команд тестирования и сведений о браузерной обработке.

2. **CyberChef — Getting started**  
   https://github.com/gchq/CyberChef/wiki/Getting-started  
   Использован для описания локальной установки, зависимостей и порядка запуска проекта.

3. **CyberChef — Node API**  
   https://github.com/gchq/CyberChef/wiki/Node-API  
   Справка о программном интерфейсе Node.js для дополнительного изучения.
